# Trine Trainer v1.0.5

Web公開用の静的サイト版です。サーバー処理やビルドは不要です。

## 収録ファイル
- `index.html`
- `app.js`
- `style.css`

## ローカル確認
`index.html` をブラウザで開いてください。

## Web公開
このフォルダの3ファイルを、静的サイトを公開できるホスティングの公開ルートへ配置してください。
`index.html` がトップページになります。

## 公開版の主なモード
- 通常練習
- 双腕暴走モード
- トライン＋破壊の翼のみ
- 1回目トラインの実在パターン指定
- Retry / Replay

Version: 1.0.1

## v1.0.5 スマホ操作
タッチ端末ではフィールド左下に仮想ジョイスティックを表示します。画面下のスキルボタンをタップして発動できます。PC操作も維持しています。

## v1.0.5
- ゲーム開始前はフィールド内に練習設定を表示。開始後にフィールドへ切り替えます。
- 縦画面向けにフィールドの下へ移動スティックを独立配置しました。

## v1.0.5
結果画面の「設定してリトライ」で開始前設定へ戻り、役割・練習モード・トライン配置を変更してから再開できます。Replayは従来どおりです。

## v1.0.5
- PC/スマホとも結果画面の「Retry」で設定画面へ戻る。
- スマホではジョイスティックの右側にスキルボタンを表示し、操作中の選択・コピー用メニューを抑制。
