# Trine Trainer v1.0.2

Web公開用の静的サイト版です。サーバー処理やビルドは不要です。

## 収録ファイル
- `index.html`
- `app.js`
- `style.css`

## ローカル確認
`index.html` をブラウザで開いてください。

## Web公開
このフォルダの3ファイルを、静的サイトを公開できるホスティングの公開ルートへ配置してください。
`index.html` がトップページになります。

## 公開版の主なモード
- 通常練習
- 双腕暴走モード
- トライン＋破壊の翼のみ
- 1回目トラインの実在パターン指定
- Retry / Replay

Version: 1.0.1

## v1.0.2 スマホ操作
タッチ端末ではフィールド左下に仮想ジョイスティックを表示します。画面下のスキルボタンをタップして発動できます。PC操作も維持しています。
